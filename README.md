# Корзинка

Планировщик меню на неделю с учётом акций Lidl. Веб-приложение (PWA): открывается в браузере и устанавливается на телефон иконкой.

- Анкета: кто ест, бюджет, ограничения, посуда, время на готовку.
- Меню на 7 дней в рамках бюджета, с калориями и кнопкой «заменить блюдо».
- Список покупок по отделам Lidl с немецкими названиями и галочками, работает без интернета.
- Раз в неделю скрипт `scripts/fetch_offers.py` обновляет `data/offers.json` с акциями Lidl (с публичных страниц marktguru.de).

Все ответы анкеты и галочки хранятся только на устройстве пользователя.

## Проверка на компьютере

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

Потом открыть http://localhost:8080
